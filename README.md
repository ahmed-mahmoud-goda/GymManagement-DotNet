# Gym Management System

## About
This is a simple web app for managing a gym.  
It helps to manage members, trainers, sessions, bookings, and membership plans.  

## Features
- Add, edit, delete members and trainers.  
- Manage membership plans.  
- Schedule and book sessions.  
- Track session status and attendance.  
- Role-based access for admins, trainers, and members.  
- Optional Redis caching for faster performance.
- Real-time updates using SignalR and Background Services.

## Technologies
- .NET Core
- MVC Architecture 
- SQL Server + Entity Framework Core  
- Redis (Caching)
- SignalR and Background Service (Real-time Event)
